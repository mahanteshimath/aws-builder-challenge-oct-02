## 4. Release sequence
1. Verified identity and region; listed Bedrock foundation models and `us.amazon.nova-*` inference profiles.
2. Created the Amplify app and `main` branch; deployed the SAM stack (API Gateway, two Lambdas, private S3, IAM roles, logs).
3. Uploaded the GeoJSON layers, built the SPA with the API URL, deployed it to Amplify and applied CSP / security headers.
4. Rebuilt the dataset on OpenStreetMap + SRTM data for Kurla and redeployed stack, data and frontend.
5. Final release with `pwsh scripts/deploy.ps1` (dataset build -> 75 tests -> headers -> SAM deploy -> S3 sync -> Amplify jobs 7-8 -> smoke test 15/15), then the browser end-to-end run (14/14) on the public URL.

## 5. How to verify
- Open the live app and `GET /api/v1/health`; `dataset_version` is `kurla-mithi-osm-1.0`.
- In CloudTrail event history, filter by user `hackermonty` on 2026-10-02 and inspect `userAgent` for `app/cortex-code-agent`.
- Re-run `python scripts/agent_proof.py --profile <profile>` to regenerate the table.
